# 🎰 Streamlit 로또 번호 생성기 (Lotto Generator)

Streamlit을 활용하여 구현한 **실시간 로또 번호 생성 프로그램**입니다.
1부터 45까지의 숫자 중 중복 없는 6개의 번호를 추첨하며, 실제 로또 공과 동일한 색상으로 번호를 직관적으로 시각화합니다.

---

## 📌 주요 기능

- **중복 없는 번호 추출**: 1~45 사이의 난수 6개를 추출하여 오름차순으로 자동으로 정렬합니다.
- **최대 5세트 번호 생성**: `[로또번호 생성]` 버튼 클릭 시 최대 5개의 번호 세트까지 순차적으로 누적 생성됩니다.
- **실제 로또 공 색상 스타일링**: 번호대별로 실제 로또 공의 색상을 반영하여 표시합니다.
  - 🟡 **1 ~ 10**: 노란색 (`#fbc02d`)
  - 🔵 **11 ~ 20**: 파란색 (`#1e88e5`)
  - 🔴 **21 ~ 30**: 빨간색 (`#e53935`)
  - 🟣 **31 ~ 40**: 보라색 (`#8e24aa`)
  - 🟢 **41 ~ 45**: 초록색 (`#43a047`)
- **전체 초기화**: `[전체 초기화]` 버튼을 제공하여 생성된 번호 세트를 한 번에 지우고 다시 시작할 수 있습니다.
- **클래스(Class) 미사용**: 절차적 및 함수형 방식으로 작성되어 간단하게 코드를 이해할 수 있습니다.

---

- **Language**: Python 3.8+

---

## 🚀 실행 방법

### 1. 프로젝트 다운로드 및 이동
프로젝트 코드가 위치한 디렉토리로 이동합니다.

### 2. 필수 라이브러리 설치
`requirements.txt`에 명시된 필요 라이브러리를 설치합니다.
```bash
pip install -r requirements.txt
```

### 3. Streamlit 앱 실행
> ⚠️ **주의**: `python 로또.py`로 직접 실행하면 `missing ScriptRunContext!` 오류가 발생합니다. 반드시 아래 명령어로 실행해 주세요.

```bash
streamlit run 로또.py
```

명령어 실행 후 자동으로 브라우저 열어 앱을 확인할 수 있습니다.
